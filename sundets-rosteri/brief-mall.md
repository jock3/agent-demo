# Briefmall

Fylls i tillsammans med Gustav. Resultatet skrivs till
`output/<datum>-<kund>/brief.md`. Arbetet startar först när alla fält är
ifyllda — inga tomma rader vidare.

```markdown
# Brief — <kund> — <datum>

**Kund:** 
**Plattformar:** 
**Format:** 
**Syfte:** räckvidd / engagemang / konvertering / awareness
**Målgrupp:** vilken av kundens definierade målgrupper
**Budskap i en mening:** 
**Måste med:** fakta, datum, priser, erbjudande
**Får inte med:** 
**Pronomen:** du / er-era (följer brand.md)
**CTA:** 
**Bildbehov:** motivkategori enligt bildmaner.md + format
**Deadline:** 
**Referens:** tidigare post i sundets-rosteri/ (filnamn `20*.md`) som ligger närmast i ton
```

## Frågor att ställa vid oklarhet

1. Om syftet är "räckvidd" men CTA:n är köpdriven — vilket gäller?
2. Om budskapet innehåller ett påstående som saknas i fakta.md — var kommer
   siffran ifrån?
3. Om plattformarna är fler än två — ska budskapet vara identiskt eller
   ska varje kanal ha egen vinkel?
4. Om bildbehovet inte matchar någon motivkategori — ska vi fota istället
   för att generera?

Fråga en sak i taget. Gissa aldrig på fakta, pris eller datum.
